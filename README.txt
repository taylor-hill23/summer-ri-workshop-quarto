SUMMER RI WORKSHOP — QUARTO WEBSITE

1. Double-click summer-ri-workshop.Rproj to open the project in RStudio.
2. Open any .qmd file to edit its page.
3. Click Render Website, or run this in the RStudio Terminal:

     quarto render

4. Preview the rendered site with:

     quarto preview

The rendered website will be written to the _site folder.

This reconstruction includes the current Home, Course Materials, Homework,
Data, and Additional Resources pages. The “2023 Course Materials” navigation
section and its homepage description were intentionally omitted.

The original site’s downloadable class files and datasets remain linked to
their published URLs, so the project stays small and editable.
